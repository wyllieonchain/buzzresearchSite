# Buzz Research Landing Page

A modern, dark-themed Next.js landing page for Buzz Research featuring smooth animations and a bee-themed design.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Project Structure

- `/app` - Next.js app directory with layout and main page
- `/components` - React components (Hero, Founders, BeeLogo)
- `/public` - Static assets
